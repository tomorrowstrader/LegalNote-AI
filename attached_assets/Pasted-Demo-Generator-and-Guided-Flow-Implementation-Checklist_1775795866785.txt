Global Implementation Rules
Rule 1: Highlight attachment

Any guided outline targeting a UI element must remain attached to that element during scrolling and layout changes.

Rule 2: Modal sequencing

Guide overlays must not appear before modal render / placement is complete.

Rule 3: Guided pacing

Cursor movement, section changes, and scroll behaviour should be intentionally paced so the prospect can clearly follow what is happening.

Rule 4: Focus control

During guided steps, unrelated controls should be non-interactable where needed to preserve flow integrity.

Rule 5: Copy tone

Avoid AI-sounding language. Use natural, professional wording throughout.

Rule 6: Left-panel guidance

Where specified, left menu items should use both:

yellow translucent highlight
black outline highlight
Rule 7: Final conversion

The end of the flow should make booking a call feel like the natural and immediate next step.
